******************************RPI 4 COMPUTE MODULE**********************************
1. Burn the image into the IO Board, by disabling the emmc boot option by putting a jumper at j2. Let the image get burnt and the OS will be installed into the PI Board, PLEASE REMOVE THE JUMPER FROM J2 BEFORE MOVING TO STEP2.
2. Place the Jumpers vertically @J6.
3. Put camera in cam1 for now(The Black part facing top) on both IO Board and the camera.
Lets enable the interface (i2c) from 
	sudo raspi-config
	
4. Install the I²C tools:
	sudo apt install -y i2c-tools
then reboot the system.

5. enter the updated configuration as it is as shown below:

#To run an RTSP stream headlessly without any crashing or configuration issues, we can use the native VLC media engine directly from your terminal session
Run the below command:
	rpicam-vid -t 0 --inline --codec libav --libav-format mpegts -o - --width 640 --height 480 --framerate 30 --nopreview | cvlc stream:///dev/stdin --sout '#rtp{sdp=rtsp://:8554/stream1}'


How to watch it on your computer:

1. Open VLC Media Player on your Windows laptop.
2. Press Ctrl + N (or go to Media -> Open Network Stream).
3. Enter your Raspberry Pi's IP address formatted precisely like this:text
		rtsp://<YOUR_RASPBERRY_PI_IP>:8554/stream1
note: port number can be changed i.e. 8554
